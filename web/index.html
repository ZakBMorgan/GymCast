      How this was measured

      These are past test forecasts, not saved live ones. Each test model was trained only on data from before the hours it predicted (walk-forward evaluation), so it never saw the answers. The error is the average difference between expected and observed people. Gaps are hours left out of the comparison. Times are New York time.
